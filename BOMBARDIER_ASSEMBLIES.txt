Bombardier Assemblies Guide

Intake
- Motors: lift (NEO) and rollers (NEO). CAN IDs are in Constants.IntakeConstants.
- Spark settings (Configs.Intake):
  - Lift: brake mode, 30A current limit
  - Rollers: coast mode, 20A current limit
- Encoders: the lift motor encoder is used for position/velocity.
  - Read position: IntakeSubsystem.getLiftPositionRotations()
  - Read velocity: IntakeSubsystem.getLiftVelocityRpm()
  - Reset: IntakeSubsystem.resetLiftEncoder()
- Change behavior:
  - Lift speeds: Constants.IntakeConstants.kLiftUpSpeed, kLiftDownSpeed
  - Roller speeds: Constants.IntakeConstants.kRollerIntakeSpeed, kRollerEjectSpeed
  - Current limits and idle mode: Configs.Intake (lift uses brake, rollers use coast)

Conveyor
- Motors: single conveyor roller motor (NEO). CAN ID in Constants.ConveyorConstants.kMotorCanId.
- Spark settings (Configs.Conveyor):
  - Conveyor: coast mode, 15A current limit
- Encoders: built-in NEO encoder for RPM feedback (ConveyorSubsystem.getVelocityRpm()).
- Change behavior:
  - Speed values: Constants.ConveyorConstants.kConveyorSpeed, kConveyorReverseSpeed
  - Current limit/idle: Configs.Conveyor

Feeder
- Motors: default is its own NEO motor (CAN ID in Constants.FeederConstants.kMotorCanId).
- Option to share the conveyor motor instead:
  - Set Constants.FeederConstants.kUseConveyorMotor = true
  - FeederSubsystem will command the ConveyorSubsystem motor instead of its own
- Spark settings (Configs.Feeder):
  - Feeder: coast mode, 15A current limit
- Encoders: if using its own motor, FeederSubsystem.getVelocityRpm() reads the NEO encoder.
- Change behavior:
  - Speed values: Constants.FeederConstants.kFeederSpeed, kFeederReverseSpeed
  - Current limit/idle: Configs.Feeder

Shooter
- Motors: two NEOs (left + right). CAN IDs in Constants.ShooterConstants.
- Spark settings (Configs.Shooter):
  - Left: coast mode, 25A current limit
  - Right: coast mode, 25A current limit
- Encoders: both built-in NEO encoders are read for RPM.
  - ShooterSubsystem.getLeftRpm(), getRightRpm(), getAverageRpm()
- Change behavior:
  - Inversion: Constants.ShooterConstants.kRightMotorInverted
  - Speed presets: Constants.ShooterConstants.kShooterOpenLoopSpeed, kShooterTargetRpm
  - Current limit/idle: Configs.Shooter

PathPlanner
- Vendor dependency installed in vendordeps/PathplannerLib.json.
- AutoBuilder configuration is in DriveSubsystem.
- PathPlanner reads robot settings from src/main/deploy/pathplanner/settings.json created by the GUI.
  - If that file is missing, autos are disabled and an error is reported to DriverStation.

Notes
- Update CAN IDs and speed constants in src/main/java/frc/robot/Constants.java.
- Tweak motor configs in src/main/java/frc/robot/Configs.java.
